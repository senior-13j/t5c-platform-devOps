# Notices and Project Provenance

## Arkadii Quest

Arkadii Quest (`Аркадия Квест`) is the current player-facing identity of this
repository. Its world is called Arkadia (`Аркадия`). Changes made for this
identity include new names and localized copy, a new visual system and brand
assets, onboarding, control changes, deployment work, and ongoing quality
improvements.

The Arkadii Quest name, compass-shield mark, wordmark, key art, application
icons, favicon, and social artwork were created specifically for the 2026
rebrand. The raster key art was generated with OpenAI image generation without
an input reference image. The social image, PNG icons, and favicon are
derivatives made for this project from that new visual system.

Arkadii Quest is an original project identity. It is not affiliated with,
endorsed by, or sponsored by RuneScape or Jagex. References to an “old-school”
RPG direction describe broad genre inspiration, not ownership of another
game's name, artwork, interface, icons, typography, music, or other protected
material.
